## Конфликты слияния
Конфликт слияния — это кейс, когда в двух разных ветках были одновременно изменены одни и те же строки одного файла. Конфликт возник из-за того, что в ветке для плавания и в ветке для бега была переписана одна и та же строка вывода хобби после моего имени. Git не смог самостоятельно решить, какое увлечение важнее, и остановил слияние. Я пофиксила этот конфликт вручную, объединив оба хобби в файле Program.cs, после чего успешно завершила коммит слияния и проверила сборку проекта.
